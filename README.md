# Dolap – UX Audit & Product Improvement Case Study

## Project Overview
This case study presents my individual UX analysis contribution to a university group project focused on the Dolap second-hand marketplace application.

The aim was to examine buyer and seller experiences, identify potential usability problems, and propose improvements.

## Research Approach
To identify potential user experience problems, I drew on:
- Publicly available user reviews
- Informal feedback from people around me
- My own experience using the application

These insights were used as a starting point for the UX evaluation, rather than as findings from a formal user research study.

## My Contributions
- Buyer and seller journey analysis
- User persona development
- Empathy mapping
- Jobs-to-be-Done (JTBD) analysis
- UX problem identification
- Product improvement proposals
- Low-fidelity wireframe design

## Key Problems Identified
- Uncertainty around shipping costs and additional fees
- Difficulties in shipping and order processes
- Trust and return-related concerns
- Notification overload and unclear information

## Proposed Improvements
- Clearer presentation of total costs
- Improved shipping process guidance
- Greater transparency in return and transaction processes
- Prioritized notifications
- Low-fidelity interface concepts for selected improvements

## Project Deliverables
The repository includes my UX analysis report and supporting wireframes.
